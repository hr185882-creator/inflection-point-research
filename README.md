# Inflection Point Research

Inflection Point Research (IPR) is the structural-forecasting layer within AURORA GRID. It tests whether a development is a genuine change in system behavior or merely temporary, cyclical, local, symbolic, or narrative-driven.

## Analytical sequence

`Baseline -> pressure point -> mechanism -> structural change -> consequence`

IPR examines:

- deviation from the established baseline
- persistence and scale
- causal mechanism
- institutional or operational constraints
- irreversibility and reversal conditions
- second-order effects
- downstream decision consequences

## Integration with AURORA GRID

IPR operates inside the full workflow:

`SCOUT -> SOURCEGRID -> K-ALIGN -> IPR -> BLACKGLASS -> CRF -> COMMAND -> AURORA GRID -> RECORD LOCK`

Its output is not accepted as a structural conclusion until the record supports a mechanism, a binding constraint, and a falsifier.

- technology adoption and platform shifts
