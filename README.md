# Inflection Point Research

Inflection Point Research (IPR) is the structural-forecasting layer within AURORA GRID. It tests whether a development is a genuine change in system behavior or merely temporary, cyclical, local, symbolic, or narrative-driven.

## Analytical sequence

`Baseline -> pressure point -> mechanism -> structural change -> consequence`

IPR examines:

- deviation from the established baseline
- persistence and scale
- causal mechanism
- institutional or operational constraints
- incentive, capability, authority, resource-flow, and behavioral change
- irreversibility and reversal conditions
- second-order effects
- downstream decision consequences
- the strongest continuity case
- the reference class for comparable apparent turning points

## Integration with AURORA GRID

IPR operates inside the active v2 workflow:

`ROUTER -> SCOUT -> SOURCEGRID -> K-ALIGN -> IPR -> BLACKGLASS-I -> CRF -> COMMAND -> BLACKGLASS-II -> RECORD LOCK`

AAIK applies evidence and risk controls across the workflow. Luna expands structural possibilities, Terra tests the record and mechanism, and Sol resolves the classification and downstream decision.

IPR output is not accepted as a structural conclusion until the record supports a mechanism, persistence case, binding constraint, reference class, strongest continuity case, and falsifier.

## Structural classifications

- **Structural** — multiple dimensions show material, persistent, causally connected change.
- **Temporary** — the development is real but driven by transient conditions.
- **Cyclical** — the development fits a recurring pattern without changing the underlying system.
- **Local** — the effect is geographically, organizationally, or functionally bounded.
- **Symbolic** — the development changes signaling or narrative more than capability or incentives.
- **Narrative** — attention changes more than the underlying system.
